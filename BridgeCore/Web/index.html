Alarms and repeat rules

Unchanged rules are preserved. Editing unsupported rules is rejected, never silently simplified. Dates in alarm/repeat JSON use ISO 8601.

Examples: [{"relativeOffset":-900}] or [{"absoluteDate":"2030-01-01T12:00:00Z"}]. Location alarm: [{"latitude":37.7,"longitude":-122.4,"radius":100,"proximity":"enter","label":"Place"}]. Empty array removes alarms. Email and URL/file alarm actions are not supported.

Example: [{"frequency":"weekly","interval":1,"daysOfWeek":[{"day":2,"week":0}]}]. Day 1 is Sunday. Optional: daysOfMonth, monthsOfYear, weeksOfYear, daysOfYear, positions, count or endDate. Empty array removes repeats.
